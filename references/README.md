# References and provenance

Keep dataset and literature provenance records here.

A provenance record should include, where applicable:

- study title and citation;
- repository accession or persistent identifier;
- source URL;
- data modality;
- species/model and experimental context;
- inclusion/exclusion decision;
- relevant sample/subject identifiers;
- download or access date;
- notes on processing and known limitations.

The canonical discovery PDF is retained at the repository root. The computational implementation should cite it as the program-level design document rather than treating its proposed methods as already validated results.
